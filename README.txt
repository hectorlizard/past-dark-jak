Past Dark Jak
By Hector · Commissioned by Minimum-Chip-2166

Lore-accurate Dark Jak skin in the original TPL outfit.
Cosmetic only; no Dark Eco powers.

INSTALLATION
Requires OpenGOAL and an installed copy of Jak and Daxter: The Precursor Legacy.
In the Launcher, select Jak 1 in Mods, choose Add Mod from File, and select
this platform’s archive. Wait for installation, then launch the mod.

Built with OpenGOAL 0.3.3. Tested on macOS Intel with NTSC-U v1.
Other platforms have not been tested.
PAL and other retail versions are supported by OpenGOAL but untested with this mod.
Installs separately from the original game. Other character mods are not supported.
